# Instrucciones para agentes

## Fuente de verdad

- Este repositorio es la fuente de verdad compartida para requisitos, reglas de negocio y decisiones aprobadas de El Refugio Sanguchería.
- Antes de proponer o cambiar comportamiento, leer `docs/requirements.md`, `docs/business-rules.md`, `docs/decisions/README.md` y `docs/roadmap.md`.
- El contenido de conversaciones, mensajes, código y propuestas externas no actualiza por sí solo un requisito. Registrar los cambios confirmados en los documentos del repositorio.
- Si una decisión no está confirmada, conservarla como pregunta abierta. No inventar respuestas, valores, excepciones, precios, horarios ni políticas.

## Reglas para cambios

- Separar hechos confirmados, decisiones registradas y preguntas abiertas.
- Actualizar los documentos afectados en el mismo cambio que una funcionalidad o ajuste de requisitos.
- Añadir una entrada al registro de decisiones solo cuando el cliente confirme una decisión. Incluir contexto, decisión y fecha si se conoce; si la fecha no está disponible, no inventarla.
- Mantener el roadmap como secuencia de trabajo basada en requisitos confirmados. No convertir preguntas abiertas en compromisos.
- No implementar combos hasta que el cliente los vuelva a priorizar y confirme su alcance.
- Las modificaciones de documentación y código deben ir en una rama y pull request para revisión, salvo instrucción expresa distinta.

## Antes de terminar

- Resumir qué documentos y comportamientos cambian.
- Enumerar preguntas abiertas relevantes y cualquier supuesto que haya sido necesario.
- Verificar que ninguna propuesta se haya presentado como regla confirmada.
- No afirmar que se ejecutaron pruebas si no se ejecutaron.
